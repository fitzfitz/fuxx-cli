# Chores 33–35 (after M11ar) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (the user's build mode: built in the session, screenshots and one review at the end). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop reads as a solid, high-contrast button and the usage badge is cut out of its gauge (33), finished corner tabs shrink to a green icon (34), and a local HTML page a program opens lands in fuxx's browser (35).

**Architecture:** 33 changes `Colors::of`'s `stop_fill`/`stop_hover` and adds `stop_square` (the theme's text as the fill, the box's own colour as the square), draws both warning dots through one `badge` helper with a 2 pt ring in `box_fill`, and a scene measures the bottom row. 34 adds `src/corner_tabs.rs` (the done tip, shared by the three tabs); `tab_words` gives no words once all is done, `corner_pill` takes the tip as a `SharedString` and draws words only when there are some. 35 first checks (browser probe) that a `file://` page loads with its CSS and images; the shim then hands a lone existing `.html`/`.htm` path (made absolute) or a `file://…html` address to `fuxx link open`, which turns an absolute page path into a `file://` URL; the API and the link router let a local page through for an auto-open only (a clicked link still can't open `file://`).

**Tech Stack:** Rust, GPUI (pinned), WebKit (WKWebView), POSIX sh, the ui-shots harness.

**Spec:** `docs/04-Development/93 - Milestone 11ar - Subagents.md`, chores 33, 34, 35 (queued 2026-11-26); mockup `/tmp/fuxx-mockups/box-states.html`.

## Global Constraints

- Provider-specific code stays in `src/providers/<agent>.rs`; generic code asks the provider.
- Reuse, no duplication; split files that bloat (`agent_box.rs`, `agent_tab.rs` are large: new pure code goes in its own module).
- Neutral example names only (my-app, retry.rs); never the user's paths.
- Per-task gate: `cargo test --bin fuxx`, `cargo clippy --all-targets`, `cargo clippy --all-targets --features ui-shots` (no new warnings in touched files), `cargo fmt --check`.
- Never run `fuxx` by name in a shell (the user's app); tests use doubles, the probe runs `target/debug/fuxx` by path.
- Keep the corner tabs' "stays until your next message" rules; only their look changes.

## Review Focus

- A `.html` name that isn't a file (`open example.com/index.html`, a folder named `x.html`): the real open, untouched (Task 3 shim cases).
- A page path with a space, `#` or non-ASCII letters: the `file://` URL is percent-encoded and loads (Task 3 `page_url` test).
- A clicked `file://` link in terminal output still opens nothing (Task 3 test on `open_link_from`'s rule).
- Stopping… (not pressable) and Force stop keep reading apart from Stop (Task 1 colour test).
- A tab that is done but whose popover is open: still a pill under the pointer, still opens/closes (Task 2 scene clicks it).
