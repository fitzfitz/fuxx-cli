## Review Focus

Things no automated test covers here, which a person would trip over:

1. **Closing the window must quit the process.** macOS GPUI defaults to "keep running with no
   windows" (`QuitMode::Default` = Explicit on macOS). → Task 2 sets `QuitMode::LastWindowClosed`; Task 3 checks it.
2. **cmd-q must quit.** GPUI ships *no* default key bindings or menus. → Task 2 binds it; Task 3 checks it.
3. **Text must actually render** (`font-kit`). → Task 1 adds it; Task 3 checks the placeholder text is visible.
4. **First launch with `runtime_shaders`** compiles the shaders at startup. A short delay is normal; a
   crash or blank window is not. → Task 3 checks it.
5. **A rev bump can silently change APIs.** → Task 1 pins the rev and checks `Cargo.lock` records it.

### Task 2: Quit on close, window title, cmd-q — ✅

**Files:** Modify `src/main.rs` (whole file)

**Interfaces:** Introduces the `Quit` action (`actions!(fuxx, [Quit])`) and the `cmd-q` binding;
M1 keeps both. Uses `application().with_quit_mode(QuitMode::LastWindowClosed)`.

> **Rust/GPUI notes.** `actions!` generates a unit struct per action. `KeyBinding::new("cmd-q", Quit, None)`
> maps a keystroke to it, and `cx.on_action` handles it app-wide. `QuitMode::LastWindowClosed`
> overrides the macOS habit of keeping apps alive with no windows.

- [x] **Step 1: Replace `src/main.rs` with exactly this**

```rust
// fuxx — Milestone 0: prove the GPUI toolchain by opening a blank window.
// The real terminal (alacritty_terminal in a GPUI view) arrives in Milestone 1.

use gpui::{
    App, Bounds, Context, KeyBinding, QuitMode, SharedString, TitlebarOptions, Window,
    WindowBounds, WindowOptions, actions, div, prelude::*, px, rgb, size,
};
use gpui_platform::application;

actions!(fuxx, [Quit]);

struct Fuxx {
    text: SharedString,
}

impl Render for Fuxx {
    fn render(&mut self, _window: &mut Window, _cx: &mut Context<Self>) -> impl IntoElement {
        div()
            .flex()
            .size_full()
            .justify_center()
            .items_center()
            .bg(rgb(0x1e1e1e))
            .text_xl()
            .text_color(rgb(0xf0f0f0))
            .child(format!("{} — M0: GPUI window is alive", &self.text))
    }
}

fn main() {
    // macOS apps normally keep running with no windows; a terminal should quit instead.
    application().with_quit_mode(QuitMode::LastWindowClosed).run(|cx: &mut App| {
        // GPUI ships no default key bindings: cmd-q does nothing until we bind it.
        cx.bind_keys([KeyBinding::new("cmd-q", Quit, None)]);
        cx.on_action(|_: &Quit, cx: &mut App| cx.quit());

        let bounds = Bounds::centered(None, size(px(800.0), px(520.0)), cx);
        cx.open_window(
            WindowOptions {
                window_bounds: Some(WindowBounds::Windowed(bounds)),
                titlebar: Some(TitlebarOptions { title: Some("fuxx".into()), ..Default::default() }),
                ..Default::default()
            },
            |_, cx| cx.new(|_| Fuxx { text: "fuxx".into() }),
        )
        .expect("failed to open the window");
        cx.activate(true);
    });
}
```
