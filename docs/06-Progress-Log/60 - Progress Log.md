### 2026-11-10 — M11o final review fixes (not merged; waiting for your on-screen check)
- **Did:** The final whole-branch review found one way a refusal could change your repo: `git switch --track` (or `-c`) for an origin branch can write the target's files into the tree and index, then fail to make the branch (a narrow clone whose fetch rule has no `:` or stores elsewhere; a name clashing as a folder, `feature` against a local `feature/x`), leaving those files staged among yours.
